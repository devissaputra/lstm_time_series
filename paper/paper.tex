\begin{abstract}
A compact LSTM is compared with persistence and Ridge autoregression for chronological next-week forecasting of the Mauna Loa CO2 series. Normalization is fitted only on the training period.
\end{abstract}
\section{Method}
Twenty-four previous weekly observations predict the next value. The first 80\% of windows are used for training and the last 20\% for evaluation.
\section{Results}

\section{Interpretation}
Ridge performs best in this recorded run. The result shows that recurrent complexity does not automatically improve a smooth, autocorrelated series.
\section{Temporal validity and reproduction}
Missing weeks use past-only forward filling. The corrected full 20-epoch experiment and CI succeeded in GitHub Actions run 36235069744. Errors are calculated in ppm after reversing training-fitted normalization. Test predictions use already observed history, not a recursive forecast from one origin.
\section{Limitations}
One seed, one test era and fixed hyperparameters limit generalization. No uncertainty interval or universal architecture ranking is claimed. The Markdown working paper provides the fuller interpretation and reproduction record.
